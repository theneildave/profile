Cost Optimisation Tips for Indian Teams

Route by Complexity

Route simple queries to GPT-4o mini or Gemini Flash. Reserve Sonnet and GPT-4o for hard reasoning tasks. A tiered approach typically cuts costs 60–80%.

Cache Repeated Prompts

Anthropic offers prompt caching at a 90% discount on cached input tokens. OpenAI has similar for GPT-4o. Cache system prompts and shared context that repeats across requests.

Trim Your Context Window

Every token costs money. Summarise conversation history instead of passing full logs. Removing 500 tokens per request × 100K requests/month saves roughly ₹2,125/month on GPT-4o.

Budget 18% GST from Day 1

Indian businesses pay 18% GST on foreign API imports (RCM). A ₹50,000/month API bill becomes ₹59,000 with GST. This is often missed in early-stage unit economics — factor it in early.
